# Messaging System - Quick Start Guide

## Overview
The new messaging system allows direct communication between donors and system administrators through an integrated messaging interface.

## Accessing Messages

### For Donors
1. **From Navigation Bar**: Click "💬 Mensajes" under "Consultas y Reportes"
2. **From Donor Summary**: Click the "💬 Mensajes" button in the welcome banner
3. **Unread Indicator**: Red badge on navigation shows unread message count

### For Admins/Data Entry
1. **From Navigation Bar**: Click "💬 Mensajes" under "Consultas y Reportes"
2. **Unread Indicator**: Red badge on navigation shows unread message count

## Using the Messaging Interface

### Layout
```
┌─────────────────────────────────────────────────┐
│  💬 Mensajes                                    │
├──────────────┬──────────────────────────────────┤
│              │  Conversation Header             │
│  User List   │  (Selected user info)            │
│              ├──────────────────────────────────┤
│  • User 1    │                                  │
│  • User 2    │  Message 1                       │
│  • User 3    │  Message 2                       │
│              │  Message 3                       │
│              │                                  │
│              ├──────────────────────────────────┤
│              │  [Type message...] [📤 Enviar]  │
└──────────────┴──────────────────────────────────┘
```

### Sending a Message
1. Select a user from the left sidebar
2. Type your message in the input field at the bottom
3. Click "📤 Enviar" or press Enter

### Replying to a Message
1. Click the "↩️" button on any message
2. The message will be shown as "Replying to:" at the top of input
3. Type your reply and send
4. Click "✕" to cancel the reply

### Marking Messages
- **Auto-Read**: Messages are automatically marked as read when you open the conversation
- **Mark as Unread**: Click the "✉️" button on a read message to mark it unread

### Visual Indicators
- **Your messages**: Blue background, aligned right
- **Their messages**: Gray background, aligned left
- **Unread badge**: Red circle with count in navigation bar
- **Read status**: "✓✓" indicator on read messages
- **Reply threads**: "↩️" icon shows which message is being replied to

## Access Permissions

### Donor Role
- ✅ Can view and send messages to Admins
- ✅ Can reply to messages
- ✅ Can mark messages as unread
- ❌ Cannot message other donors
- ❌ Cannot see all system messages

### Admin & Data Entry Roles
- ✅ Can view messages from all donors
- ✅ Can send messages to any donor
- ✅ Can reply to messages
- ✅ Can mark messages as unread
- ✅ Can view all messages (Admin endpoint)

### Read-Only Role
- ❌ No access to messaging system

## Best Practices

### For Donors
- Use messages for questions about your donations or payments
- Check for unread messages regularly (badge indicator)
- Reply to admin messages promptly
- Be clear and specific in your questions

### For Admins
- Respond to donor messages promptly
- Use replies to maintain context in conversations
- Mark important messages as unread for follow-up
- Keep messages professional and helpful

## Troubleshooting

### "No se encontró su perfil de donante"
- Contact administrator to link your user account to a donor profile

### Cannot send messages
- Verify you have the correct role (Donor, Admin, or DataEntry)
- Check that you're not trying to message another donor (donors can only message admins)

### Unread count not updating
- Refresh the page
- The count updates automatically every 30 seconds

### Messages not appearing
- Verify you've selected a user from the sidebar
- Check your internet connection
- Refresh the page

## Tips
- 💡 The unread count refreshes every 30 seconds automatically
- 💡 Messages are ordered chronologically (oldest first)
- 💡 Timestamps show in DD/MM/YYYY HH:MM format
- 💡 Reply references show first 50 characters of original message
- 💡 Mobile-friendly design adapts to smaller screens

## Support
If you encounter any issues with the messaging system, contact your system administrator.
